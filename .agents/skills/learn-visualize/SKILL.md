# Learn Visualize

Use Mermaid for dependencies, flows, sequences, states, trees, comparisons, and
timelines. Use SVG for exact coordinates, vectors, plots, and geometry. Keep one
idea per visual, verify it before embedding, save Obsidian assets in
`06 Медиа/Самообучение/viz/`, and embed with `![[filename|500]]`. If rendering is
unavailable, use a fenced Mermaid block and mark it unverified.
